# CareLynx SEO implementation

Base URL: https://carelynxpvtltd.vercel.app/ (confirmed Search Console property).

## Included
- Unique title, description, canonical, Open Graph and Twitter metadata for Home, Partner and Developers pages.
- Organization schema with brand CareLynx and legal name CareLynx Pvt Ltd; founder/co-founder; WebSite and Developers page structured data.
- robots.txt and sitemap.xml. Draft legal policy placeholders have noindex until replaced with reviewed policies.
- Resized favicon, app icons, organization logo and social preview from the supplied logo.

## After deployment
1. Deploy all files together to Vercel. Confirm /robots.txt, /sitemap.xml, and logo URLs load.
2. In Google Search Console, use the already-verified URL-prefix property https://carelynxpvtltd.vercel.app/. Keep the Google HTML verification file in the deployed root.
3. Submit sitemap.xml in Search Console > Sitemaps. Use URL Inspection > Request Indexing for the home, partnership and developers pages.
4. Use Rich Results Test and PageSpeed Insights, then monitor Search Console Pages and Performance.
5. If you later acquire a domain, update all absolute URLs and set 301 redirects before re-submitting the sitemap.

Important: Indexing, rankings, site name, logo and rich-result display are determined by Google and cannot be guaranteed. Never publish unreviewed legal-policy placeholders as final policies.
